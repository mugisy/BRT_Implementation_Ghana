# BRT_Implementation_Ghana

This repository contains a modeling-focused study on commuter responses to Bus Rapid Transit (BRT) implementation in Ghana.

## Project objective

Use survey data to:
- identify the most critical BRT success factors, and
- estimate how those factors influence commuters' willingness to switch from their current transport mode to the BRT system.

## Scope

The repository is intended to support:
- survey-based factor analysis and feature selection,
- commuter mode-switch modeling, and
- interpretation of model outputs for policy and planning decisions.
